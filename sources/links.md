# Source links

One per line: URL — what it is — which week(s) it feeds.

## Beginner on-ramps to dmol.pub (added 2026-09-02)
- https://dmol.pub — target text: Deep Learning for Molecules & Materials (assumes Python+numpy; ch. A–B teach ML basics)
- https://education.molssi.org/python_scripting_cms/ — MolSSI Python Scripting for Computational Molecular Science — Python from zero via chemistry data — pre-course/week 1
- https://pythoninchemistry.org/intro_python_chemists/intro.html — Intro to Python for Chemistry (open textbook, no prior programming) — pre-course
- https://github.com/weisscharlesj/SciCompforChemists — Scientific Computing for Chemists with Python (numpy/pandas/matplotlib/sklearn Jupyter book) — weeks 1–2
- https://github.com/ML4chemArg/Intro-to-Machine-Learning-in-Chemistry — J.Chem.Ed. "Gentle Introduction to ML for Chemists" workshop notebooks — first ML
- https://github.com/BingqingCheng/ML-in-chemistry-101 — ML in Chemistry 101 course notebooks — first ML
- https://github.com/xuhuihuang/mlchem — MLChem Jupyter tutorials (Huang group) — first ML
- https://github.com/schwallergroup/ai4chem_course — EPFL CH-457 AI for Chemistry (closest full-course analogue; Colab notebooks) — mid-course benchmark
- https://github.com/volkamerlab/teachopencadd — TeachOpenCADD talktorials (RDKit, cheminformatics→ML pipelines) — bridge
- https://github.com/PatWalters/practical_cheminformatics_tutorials — Practical Cheminformatics tutorials — bridge
- https://deepchem.readthedocs.io/en/latest/get_started/tutorials.html — DeepChem tutorials — bridge directly into dmol.pub deep-learning chapters
