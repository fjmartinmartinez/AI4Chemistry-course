# Prompt — Build assessment items

---
Write assessment items for week(s) NN based on the approved outlines. For each item: state the learning objective(s) tested, the item (question/task), model answer, and marking scheme with point allocation. Mix conceptual and computational items; computational ones must be solvable with the module environment and taught material only. Calibrate difficulty: ~60% attainable by a student who followed the lectures, with discriminating headroom at the top. Save to `assessments/weekNN_<type>.md` (or .ipynb for coding coursework) with a solutions counterpart kept separate from anything student-facing.
