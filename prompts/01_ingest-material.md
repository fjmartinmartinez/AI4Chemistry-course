# Prompt — Ingest new source material

Use when new files land in `sources/` or new links in `sources/links.md`.

---
Read the newly added items in `sources/` (list them). For each, produce a 3–5 line index entry: what it is, quality/level, which syllabus weeks it can feed, and any licensing/attribution constraint. Append the entries to `sources/INDEX.md` (create if missing). Flag material that contradicts other sources or contains errors. Do not summarise beyond what is needed for retrieval — this is an index, not a review.
