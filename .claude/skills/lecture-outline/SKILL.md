# Lecture outline

Follow `prompts/02_lecture-outline.md` at the project root, with `CLAUDE.md` conventions. In short:

1. Read `admin/syllabus.md`, `admin/learning-outcomes.md`, `sources/INDEX.md` (run the ingest prompt first if sources are unindexed), and this week's sources.
2. Copy `lectures/_template/` → `lectures/week-NN_<topic>/`; fill `outline.md` fully (objectives mapped to LOs, concept sequence with chemistry anchors, notebook plan with exercises, slides plan, assessment hooks, sources used).
3. Critique the draft (authentic examples? realistic load? assessable objectives?) and end with open questions for the instructor.
4. Stop for approval — never continue to notebook or slides in the same run.
