Reading list and additional resources

Every notebook is self-contained and includes its own further-reading cell at the end. This page collects everything in one place for browsing ahead or catching up. Nothing here is required beyond what a session's notebook points you to — it's optional depth.

General / pre-course resources

  • dmol.pub — Deep Learning for Molecules & Materials — the module's core text from Week 4 onward (assumes Python + NumPy).
  • MolSSI — Python Scripting for Computational Molecular Science — Python from zero, taught through chemistry data.
  • Introduction to Python for Chemistry — open textbook, no prior programming assumed.
  • Scientific Computing for Chemists with Python — NumPy/pandas/matplotlib/scikit-learn as a Jupyter book (Weeks 1–2).
  • A Gentle Introduction to Machine Learning for Chemists — J. Chem. Ed. workshop notebooks.
  • ML in Chemistry 101 — course notebooks.
  • MLChem — Jupyter tutorials (Huang group).
  • EPFL CH-457, AI for Chemistry — the closest full-course analogue; notebooks viewable/runnable directly from GitHub.
  • TeachOpenCADD — RDKit and cheminformatics-to-ML talktorials.
  • Practical Cheminformatics Tutorials (Pat Walters).
  • DeepChem tutorials — a bridge directly into dmol.pub's deep-learning chapters.

Week 1 — Python bootcamp

  • A: MolSSI 01, Introduction; 02, File parsing; 06, Functions; SciComp ch. 0, ch. 1
  • A, further reading: EPFL 01a, Python crash course
  • B: SciComp ch. 4, NumPy; ch. 3, Matplotlib; MolSSI 04, Tabular data; 05, Plotting

  • A: SciComp ch. 5, Pandas; EPFL 01b, Pandas; EPFL 01d, RDKit basics

Week 3 — Regression and model assessment

Week 4 — Classification and unsupervised learning

  • A: dmol.pub Classification; Kernel learning (qualitative)

Week 5 — Deep learning I

Week 6 — Representations and inductive bias

Week 7 — Graph neural networks

Week 8 — Sequences, attention, chemical LLMs

Week 9 — Generative models and explainability
